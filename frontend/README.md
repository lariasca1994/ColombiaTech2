# Alquiler de vivienda · Frontend

Aplicación web en React 18 con Vite, Redux Toolkit, React Router y Tailwind CSS. Adaptable a
celular, tablet y computador, con tema claro y oscuro, e instalable como aplicación.

```bash
npm install
cp .env.example .env   # URL del backend
npm run dev            # http://localhost:5173
npm run build          # compilación de producción
```

Uso de la plataforma: [manual de usuario](../docs/MANUAL.md).
